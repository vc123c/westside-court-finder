# Westside Court Finder

Free map of every public basketball court, gym, tennis court and field on the LA Westside, showing when each one is free to play, paid, booked for leagues, or closed.

Every schedule links to its source (LA Rec and Parks, Santa Monica, Culver City, Beverly Hills, OpenStreetMap). Data collected Nov. 2026; schedules change each season, so call before you go.

The whole app is one file, `index.html`, with no build step.
